ABOUT TRACKEASE

A simple approach to parcel tracking

TrackEase is an online parcel tracking system developed using HTML, CSS and JavaScript. It provides a simple interface where users can enter a tracking ID and view predefined parcel information.

The project also demonstrates the use of Git for managing project files, recording changes, creating branches, merging updates and maintaining different versions of the project.
